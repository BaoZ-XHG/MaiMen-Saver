# WorkBuddy 对话上下文

> 本文件记录使用腾讯 WorkBuddy 智能体开发本项目的对话上下文，用于核验「WorkBuddy 专项奖励」联动条件。

## 项目概述

- 项目名称：麦门算账员（MaiMen Saver）
- 项目方向：省钱 / 组合优化
- 开发工具：腾讯 WorkBuddy

## 开发过程中的关键对话要点

1. **需求**：结合麦当劳 MCP 能力，设计并开发一个「省钱方向」的参赛 Skill。
2. **调研**：通过 WorkBuddy 加载麦当劳 MCP 工具清单（`query-meals`、`query-store-coupons`、`query-promotions`、`calculate-price` 等），确认可用的省钱相关能力。
3. **差异化设计**：结合排行榜现状，确定「确定性组合优化求解器」这一差异化切入点，区别于「纯查询类」省钱项目。
4. **实现**：在 WorkBuddy 中完成核心求解器（贪心 + 完全背包）、MCP 集成层、CLI 入口与单元测试的编写与调试。
5. **验证**：运行 7 个单元测试全部通过，并跑通 CLI Demo 输出最优省钱方案。

## 结论

本项目从创意构思、架构设计、编码实现到测试验证的全流程均在腾讯 WorkBuddy 智能体辅助下完成。
